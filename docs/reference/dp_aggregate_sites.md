# Aggregate Differentially Private Site Summaries Across a Federation

Aggregate Differentially Private Site Summaries Across a Federation

## Usage

``` r
dp_aggregate_sites(site_summaries)
```

## Arguments

- site_summaries:

  List of `"dicomtk_fl_site_summary"` objects.

## Value

A list with `n_sites`, `total_count`, `weighted_mean`, and `site_ids`.
